## Bugs the runs found, all fixed with a test

| # | Found in | Bug | Fix |
|---|---|---|---|
| 1 | gate CLI test | In a 3-case plan, a file 2 cases cover counted as "shared" (30% rule), so nothing was selected by path | Shared needs a plan of 20 or more cases (Q37 amended) |
| 2 | D4 | At `--done` the drafts already exist, so they were listed as "keep" and nothing moved into the plan | A manual case's unrecorded script is a draft |
| 3 | D4 | Publishing (link and Script line) changed the ledger hash, so every recorded script looked outdated, and lost its "proven" mark | Scripts are compared with the TestGen case's own hash |
| 4 | D4 | An edit after `--done` was reported as generic "uncommitted changes" | Its own message, with the commands to re-record |
| 5 | D4 | No first-pass tracking: a re-recorded script that failed wasn't labelled | Scripts are "new" until they pass once (`proven` in `.qamaster/drafts.json`) |
| 6 | D4 | `--done` blocked until every listed case had a script | Undrafted cases stay manual under Not run (Q39 amended) |
| 7 | publish test | macOS `/var` versus `/private/var` paths hid pushed scripts | Paths are compared as git reports them (real paths) |
