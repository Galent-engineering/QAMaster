## Why
The 0.2.0 publish walkthrough scored 3 out of 5. Publish waited for a yes, refused an unreviewed run, re-published idempotently and caught a conflict. But six problems stop it being trusted with a real test plan. The gate in [0.3.0](0.3.0.md) builds on publish's tags, smoke set, plan name and review record. So the problems in those parts get fixed first, and they're released on their own so the publish walkthrough can be run again.
