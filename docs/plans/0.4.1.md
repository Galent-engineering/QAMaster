## Why
Your manual run on AgentMesh (FastAPI plus Streamlit, Azure DevOps as the store) was the first on an API-first app. It worked end to end, but the ADO settings took four doctor runs to get right, the screen map mixed API endpoints in with screens, and TestGen fought the validator. These are fixes: no new command, flag or config key, so this is a patch release (Q46). Treating FastAPI as supported is the one borderline item, kept here by your choice because the scan already claims Python stacks.
