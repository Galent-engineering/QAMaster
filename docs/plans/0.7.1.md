## Why
0.6.0 and 0.7.0 were built back to back, and each left a short list of fixes: Q56 (a republish replaces `path:` tags, decided after 0.7.0 shipped), crawl and scan gaps that make the DSM miss elements or invent routes, generated `.feature` files that drop what a case says, and small gaps in 0.6.0's setup, settings template and tests. This release takes those fixes.

No new command, flag, config key or file format, so this is a patch release (Q46). A fix that turns out to need one is not built here: it is reported as moved, with where it goes.

## Items
Each is built test-first: a failing `node:test` against fakes first, then the fix. Doc-only parts are checked by reading them against the code. The four groups own separate files and are built in parallel, each on its own branch, then replayed onto `release/0.7.1`.
