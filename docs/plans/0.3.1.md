## Why
0.3.0 works end to end, but on a clean machine its first run goes wrong in ways a user can't tell apart from real failures:
- A missing browser, or a missing system library for it, is reported as a failed test.
- `qam plan` downloads about 240 MB without asking.
- `qam doctor` checks none of what the gate needs, and running it blocks the next plan.
- A machine without git gets a stack trace.

0.3.1 makes every prerequisite either checked with a fix in the message, or installed only after a yes.
