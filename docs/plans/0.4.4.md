## Why
Your 0.4.3 run on a signed-in React app with a FastAPI backend went end to end on one module and found 30 things. The high ones change where the gate keeps its state, how the crawl handles a sign-in and what fails a case: those are features, in 0.6.0 and 0.7.0. This release takes the rest that cost a manual workaround or a read of the source: unclear messages, missing docs, and a few checks that let mistakes through.

No new command, flag, config key or file format, so this is a patch release (Q46).
