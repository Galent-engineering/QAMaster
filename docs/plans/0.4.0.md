## Why
The first full working plugin (0.3.0) left the store conflict handling thin, the selection with one preset, and the DSM crawl slow on big apps. These are features users will notice, so this is a minor release, and it comes after the 0.3.3 fixes.

## Before you start
Item 3 adds a flag, so it needs a decision entry (Q48) accepted first. Item 8 is decided in Q47. Item 6 changes the crawl's behaviour: record the timings before and after on the same app, so the claim of faster crawls is measured.

## Release
Bump to 0.4.0 (your yes), update [releases.md](../releases.md), rebuild the zips, and load the plugin zip in Claude desktop.

## Verification
Test-first with fakes for items 1–5 and 8; for 6 and 7, timings on a real app. Then `npm run check` and `claude plugin validate .`.
