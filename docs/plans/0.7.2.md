## Why
The walkthrough on TodoApp (0.7.1) found 21 findings and the observer 23 feedback entries. Most are messages that hide a state, a parsing fault, or a missing check. A few are behaviour: they change what a gate run says or refuses. Q46 says a patch adds no command, flag, config key, file format or behaviour a user must learn, so this release builds the first kind and **moves the second kind to a decision** (below), with a recommendation for each.

## Items
Each is built test-first: a failing `node:test` against fakes, then the fix. Message-only changes are checked by a test that reads the new text.
