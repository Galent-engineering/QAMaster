## Why
Your run of 0.4.1 in Claude desktop on a plain static site (`dummy-static-website`, five HTML pages and no framework) went end to end: setup, DSM, TestGen, 36 cases published to Azure DevOps, automation, and a gate verdict of PASS 36 of 36. It was the first run on an app with no router, and it found that the single-page-app fix from 0.4.1 (item 6) drops real pages that share a nav menu. That one limited the test cases too (W7). The rest are names that disagree, settings read from the wrong folder, and messages that don't say what to do next.

These are fixes: no new command, flag, config key or file format, so this is a patch release (Q46). The features the run asked for (a local store before publish, several publish destinations, a gate run with no git change, shared step wording) go to 0.6.0.
